# Коллективные аккаунты

**Русскоязычные underhood-аккаунты** — каждую неделю пишет новый автор: фронтендер, мобильный
разработчик, начинающий, человек, переехавший за границу.

Способ увидеть профессию изнутри: не отредактированная статья, а рабочая неделя от первого лица.
